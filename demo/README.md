# ESG Hybrid Index — Multi-Factor Explorer

**Verifiable research demo** for the paper *What Does Public-Data ESG Measure? A Transparent Multi-Factor Mid-Cap Index, Its In-Sample Validation Pitfalls, and an Out-of-Sample Test* (269 mid-caps: 181 US + 88 India; +45 large-cap reference firms).

> **Academic research demonstration — not financial advice.** Out of sample (2026-04-02 → 2026-09-23) the composite did not predict returns; higher ESG predicted lower future volatility. Any return shown is a trailing, pre-snapshot figure.

## What this Space verifies

- **Company Explorer** — 10-factor radar + ESG rating (AAA–CCC) + rank
- **Company Comparison** — side-by-side radar + profile-weighted recommendation
- **Investment Screener** — threshold filter (ESG/financial/volatility/sector) + profile-ranked screening
- **Portfolio Builder** — equal-weighted aggregate vs universe + sector pie
- **Index Methodology** — interactive weight sliders (auto-normalized) → live re-ranking
- **About & Methodology** — full pipeline, provenance, limitations, and links

Every displayed number traces to `data/processed/indexed_data.csv` (generated by `scripts/03_build_index.py`) — no hardcoded demo values.

## Dataset

`data/processed/indexed_data.csv` — N=314 (269 mid-cap analytical universe + 45 large-cap reference firms). Single cross-sectional snapshot at the close of 2026-04-02. Regenerate via `python scripts/run_all.py --skip-download`.

## Reproducibility

The Space bundles the generated `indexed_data.csv` and `config/index_config.yaml`. Re-running `scripts/03_build_index.py` on identical `data/raw/` yields bit-identical outputs (seed 42, deterministic winsorization/imputation).

This directory **is** the deployable Space. Pushing it to `hf.co/spaces/<username>/esg-hybrid-index` (SDK: Gradio, hardware: CPU basic) auto-builds the demo. See `docs/DEMO.md` for exact steps.
