## 2. Validation errors (in-sample designs that cannot fail)

* **Trailing returns as "returns".** `price_momentum_*` end on the snapshot
  date; ICs against them are not predictive.
* **`forward_quality_proxy` is contemporaneous**, built from ROA/ROE/margins/
  growth that also feed several factors.
* **Profile weights tuned on in-sample momentum ICs** (Feb-2026 weights in
  git `f77385e`, revised July 2026 in `fa68391`). The OOS test also reports the
  Feb-2026 and equal weights.
* **E residualisation on `financial_score`** was described but never ran
  (ESG is built before `financial_score` exists). The claim was removed.

## 3. Manuscript claims withdrawn

The following could not be reproduced from the code: walk-forward "165 splits,
IC 0.12–0.38"; Fama–MacBeth coefficients; the factor-ablation appendix table;
the financial-validation appendix table; "12 quarterly periods, 100 % beat"; a
"flipped" value signal. Also withdrawn: the high-cap "generalisation"
(ρ = 0.9993 measured only the effect of adding 45 firms to the percentile
reference set; Kendall W = 0.933 measured agreement between profiles); Kendall
τ = 1.000 bootstrap stability; source counts "213/276 Yahoo, 102/276 SEC, 6/276
proxy" (these were dominant-source labels over all 321 firms); MDE 0.11 (the
correct value at N≈260–270 is ≈0.17).

## 4. Genuine out-of-sample test (new, `scripts/25_out_of_sample_evaluation.py`)

Window (2026-04-02, 2026-09-23]; universe, weights and scores frozen at the
snapshot; hypotheses fixed before post-snapshot prices were downloaded (not
externally pre-registered); one-sided tests with Holm correction.

| Hypothesis | Result |
|---|---|
| H1 balanced composite IC > 0 (country-neutral return) | Not supported (IC −0.094, 95 % CI [−0.22, 0.04]) |
| H2 ESG predicts lower realised vol given trailing vol | Supported (partial ρ −0.163, Holm p 0.013) |
| H3 top-19 portfolio beats the universe | Not supported (+1.9 pp, CI ≈ [−11, 11]) |

9 firms were acquired during the window; survivorship bounds are reported and
do not change any conclusion.

## 5. Remaining limitations

One six-month window in a rising market (MDE ≈ 0.17); E/S pillars are
financial proxies; ISS governance data availability; candidate list is not a
point-in-time membership history; results gross of costs. See Paper §VII.
