# Demo — Public Research Verification (Hugging Face Spaces)

> The demo uses **the actual research implementation/results**, not a simplified fake model.  
> Every displayed number traces to `data/processed/indexed_data.csv` or `reports/tables/*.csv` generated by `scripts/run_all.py`.

## 1. What the Demo Does

Interactive verification of the 10-factor (9 deployed) ESG-integrated index for **314 companies** (269 mid-cap + 45 large-cap reference firms; snapshot 2026-04-02):

| Tab | Verifies |
|-----|----------|
| **Company Explorer** | Single-company deep dive: 10-factor radar + ESG rating (AAA–CCC) + rank |
| **Company Comparison** | Side-by-side radar + weighted recommendation by investor profile |
| **Investment Screener** | Threshold filter (ESG / financial / volatility / sector) + profile-ranked screening |
| **Portfolio Builder** | Equal-weighted aggregate vs universe radar + sector diversification pie |
| **Index Methodology** | Interactive **weight sliders** (auto-normalized) → live re-ranking; methodology table |

No live trading, no forward-return claims — all "returns" are cross-sectional momentum proxies (disclosed in-app).

## 2. Local Run

```bash
pip install -r requirements.txt
python scripts/03_build_index.py   # ensure data/processed/indexed_data.csv is current
python app.py
# → http://localhost:7860
```

`app.py` reads `data/processed/indexed_data.csv` + `config/index_config.yaml` at startup. No database, no external API at runtime.

## 3. Deployment — Hugging Face Spaces (Gradio)

The Space at **`hf.co/spaces/<username>/esg-hybrid-index`** is the canonical public demo (link from paper + GitHub).

### 3.1 Deployable Bundle

```

├── app.py                     # ← copy of repo app.py (or symlink)
├── requirements.txt           # ← minimal runtime deps (see 3.3)
```

Simpler (recommended): push the **whole repository** as the Space — `app.py` at root is auto-detected by HF.

### 3.2 Exact Deployment Steps

1. **Create the Space**

   - Go to https://huggingface.co/new-space
   - Name: `esg-hybrid-index` (or `<username>/esg-hybrid-index`)
   - SDK: **Gradio**
   - Hardware: **CPU basic** (no GPU needed)
   - Visibility: **Public**
   - *Note (2026):* Creating Gradio Spaces via the `huggingface_hub` API now requires a PRO subscription (`402 Payment Required`). If API creation fails, **create the Space manually via the HF website UI** (still free via UI), then push via `git` as in step 2. The HF token is stored globally (see §6) so `git push` will authenticate automatically.

2. **Push the code**

   ```bash
   # From the repository root
   git remote add space https://huggingface.co/spaces/<username>/esg-hybrid-index
   # Or clone the Space and copy files:
   git clone https://huggingface.co/spaces/<username>/esg-hybrid-index hf-space
   cp app.py hf-space/
   cp requirements.txt hf-space/
   # Include the generated data snapshot (or reference a Dataset — see 3.4)
   mkdir -p hf-space/data/processed hf-space/config
   cp data/processed/indexed_data.csv hf-space/data/processed/
   cp config/index_config.yaml hf-space/config/
   # HF Space card
   cp demo/README.md hf-space/README.md   # or write per 3.3 below
   cd hf-space && git add . && git commit -m "deploy: esg-hybrid-index demo" && git push
   ```

3. **Verify**

   - Space builds automatically (watch **Logs** tab).  
   - Health check: open the Space URL, try **Company Explorer → ZS** → radar renders, info card shows rank, methodology sliders respond.

## 8. Troubleshooting

| Symptom | Fix |
|---------|-----|
| `FileNotFoundError: indexed_data.csv` | Run `python scripts/03_build_index.py` first |
| HF build fails (`gradio` not found) | Ensure `requirements.txt` includes `gradio>=4.44.0` and `app_file: app.py` in Space card |
| Radar blank | Check `indexed_data.csv` has 10 factor columns; verify `config/index_config.yaml` profiles exist |
| Weights don't sum to 1 | App auto-normalizes; if `Index Methodology` sum ≠ 1.0, check slider ranges |
